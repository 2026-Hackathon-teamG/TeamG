한결은행 Open API v1

제휴사와 내부 시스템이 사용하는 고객 조회 API입니다.

GET /api/v1/customers

고객 한 명의 기본 정보를 조회합니다. 로그인 세션이 필요합니다.

파라미터설명
id고객 번호 (정수)

응답 예시

{
  "id": 1001,
  "name": "홍길동",
  "phone": "010-0000-0000",
  "email": "user@example.com",
  "balance": 1500000
}

오류

  • 401 로그인 필요
  • 404 고객 없음

내부 시스템 연동

사내 배치 시스템은 X-Internal-Request: true 헤더로 호출합니다.
